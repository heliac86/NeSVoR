Use the NeSVoR algorithm to reconstuct a high-quality and coherent 3D volume from multiple stacks of 2D slices. This command can be applied to both rigid (e.g., brain) and non-rigid (e.g. uterus) motion. It also includes several optional preprocessing stpes: 

1. ROI masking/segmentation from each input stack with a CNN (only for fetal brain); 
2. N4 bias filed correction for each stack; 
3. Quality and motion assessment of each stack, which can be used to rank and filter the data; 
4. Motion correction with SVoRT (only for fetal brain) or stack-to-stack registration. 

inputs:
  --input-stacks str [str ...]                    Paths to the input stacks
                                                  (NIfTI). (default: None)
  --thicknesses float [float ...]                 Slice thickness of each
                                                  input stack. If not
                                                  provided, use the slice gap
                                                  of the input stack. If only
                                                  a single number is provided,
                                                  Assume all input stacks have
                                                  the same thickness.
                                                  (default: None)
  --input-slices str                              Folder of the input slices.
                                                  i.e., the motion corrected
                                                  slices generated by `nesvor
                                                  register`. If input-slices
                                                  are provided and input-
                                                  stacks will be ignored.
                                                  (default: None)

input stacks masking:
  --stack-masks str [str ...]                     Paths to masks of input
                                                  stacks. (default: None)
  --volume-mask str                               Paths to a 3D mask which
                                                  will be applied to each
                                                  input stack. (default: None)
  --stacks-intersection                           Only consider the region
                                                  defined by the intersection
                                                  of input stacks. Will be
                                                  ignored if `--volume-mask
                                                  <#volume-mask>`__ is
                                                  provided. (default: False)
  --background-threshold float                    pixels with value <= this
                                                  threshold will be ignored.
                                                  (default: 0)
  --otsu-thresholding                             Apply Otsu thresholding to
                                                  each input stack. (default:
                                                  False)

outputs:
  --output-volume str                             Paths to the reconstructed
                                                  volume (default: None)
  --output-slices str                             Folder to save the motion
                                                  corrected slices (default:
                                                  None)
  --simulated-slices str                          Folder to save the simulated
                                                  (extracted) slices from the
                                                  reconstructed volume
                                                  (default: None)
  --output-model str                              Path to save the output
                                                  model (.pt) (default: None)
  --output-json str                               Path to a json file for
                                                  saving the inputs and
                                                  results of the command.
                                                  (default: None)

outputs sampling:
  --output-resolution float                       Isotropic resolution of the
                                                  reconstructed volume
                                                  (default: 0.8)
  --output-intensity-mean float                   mean intensity of the output
                                                  volume (default: 700.0)
  --inference-batch-size int                      batch size for inference
                                                  (default: None)
  --n-inference-samples int                       number of sample for PSF
                                                  during inference (default:
                                                  None)
  --output-psf-factor float                       Determind the psf for
                                                  generating output volume:
                                                  FWHM = output-resolution *
                                                  output-psf-factor (default:
                                                  1.0)
  --sample-orientation str                        Path to a nii file. The
                                                  sampled volume will be
                                                  reoriented according to the
                                                  transformatio in this file.
                                                  (default: None)
  --sample-mask str                               3D Mask for sampling INR. If
                                                  not provided, will use a
                                                  mask esitmated from the
                                                  input data. (default: None)

  --segmentation                                  Perform 2D fetal brain
                                                  segmentation/masking for
                                                  each input stack. (default:
                                                  False)
  --batch-size-seg int                            Batch size for segmentation
                                                  (default: 16)
  --no-augmentation-seg                           Disable inference data
                                                  augmentation in segmentation
                                                  (default: False)
  --dilation-radius-seg float                     Dilation radius for
                                                  segmentation mask in
                                                  millimeter. (default: 1.0)
  --threshold-small-seg float                     Threshold for removing small
                                                  segmetation mask (between 0
                                                  and 1). A mask will be
                                                  removed if its area <
                                                  threshold * max area in the
                                                  stack. (default: 0.1)

N4 bias field correction:
  --bias-field-correction                         Perform bias field
                                                  correction using the N4
                                                  algorithm. (default: False)
  --n-proc-n4 int                                 number of workers for the N4
                                                  algorithm. (default: 8)
  --shrink-factor-n4 int                          The shrink factor used to
                                                  reduce the size and
                                                  complexity of the image.
                                                  (default: 2)
  --tol-n4 float                                  The convergence threshold in
                                                  N4. (default: 0.001)
  --spline-order-n4 int                           The order of B-spline.
                                                  (default: 3)
  --noise-n4 float                                The noise estimate defining
                                                  the Wiener filter. (default:
                                                  0.01)
  --n-iter-n4 int                                 The maximum number of
                                                  iterations specified at each
                                                  fitting level. (default: 50)
  --n-levels-n4 int                               The maximum number of
                                                  iterations specified at each
                                                  fitting level. (default: 4)
  --n-control-points-n4 int                       The control point grid size
                                                  in each dimension. The
                                                  B-spline mesh size is equal
                                                  to the number of control
                                                  points in that dimension
                                                  minus the spline order.
                                                  (default: 4)
  --n-bins-n4 int                                 The number of bins in the
                                                  log input intensity
                                                  histogram. (default: 200)

stack assessment:
  --metric {ncc,matrix-rank,volume,iqa2d,iqa3d,none}
                                                  Metric for assessing input
                                                  stacks. 1. ``ncc`` (↑):
                                                  cross correlaiton between
                                                  adjacent slices; 2.
                                                  ``matrix-rank`` (↓): motion
                                                  metric based on the rank of
                                                  the data matrix; 3.
                                                  ``volume`` (↑): volume of
                                                  the masked ROI; 4. ``iqa2d``
                                                  (↑): image quality score
                                                  generated by a `2D CNN <http
                                                  s://arxiv.org/abs/2006.12704
                                                  >`_ (only for fetal brain),
                                                  the score of a stack is the
                                                  average score of the images
                                                  in it; 5. ``iqa3d`` (↑):
                                                  image quality score
                                                  generated by a `3D CNN <http
                                                  s://github.com/FNNDSC/pl-
                                                  fetal-brain-assessment>`_
                                                  (only for fetal brain); 6.
                                                  ``none``: no metric used for
                                                  assessment. **Note**: (↑)
                                                  means a stack with a higher
                                                  score will have a better
                                                  rank. (default: none)
  --filter-method {top,bottom,threshold,percentage,none}
                                                  Method to remove low-quality
                                                  stacks. 1. ``top``: keep the
                                                  top ``C`` stacks; 2.
                                                  ``bottom``: remove the
                                                  bottom ``C`` stacks; 3.
                                                  ``threshold``: remove a
                                                  stack if the metric is worse
                                                  than ``C``; 4.
                                                  ``percentatge``: remove the
                                                  bottom (``num_stack * C``)
                                                  stacks; 5. ``none``: no
                                                  filtering. The value of
                                                  ``C`` is specified by
                                                  `--cutoff <#cutoff>`__.
                                                  (default: none)
  --cutoff float                                  The cutoff value for
                                                  filtering, i.e., the value
                                                  ``C`` in `--filter-method
                                                  <#filter-method>`__
                                                  (default: None)
  --batch-size-assess int                         Batch size for IQA network
                                                  (default: 8)
  --no-augmentation-assess                        Disable inference data
                                                  augmentation in IQA network
                                                  (default: False)

rigid registration:
  --registration {svort,svort-only,svort-stack,stack,none}
                                                  The type of registration
                                                  method applied before
                                                  reconstruction. #.
                                                  ``svort``: try SVoRT and
                                                  stack-to-stack registration
                                                  and choose the one with
                                                  better NCC; #. ``svort-
                                                  only``: only apply the SVoRT
                                                  model; #. ``svort-stack``:
                                                  only apply the stack
                                                  transformations of SVoRT; #.
                                                  ``stack``: stack-to-stack
                                                  rigid registration; #.
                                                  ``none``: no rigid
                                                  registration. **Note**: The
                                                  SVoRT model can be only
                                                  applied to fetal brain data.
                                                  (default: svort)
  --svort-version {v1,v2}                         Version of SVoRT model
                                                  (default: v2)
  --scanner-space                                 Perform registration in the
                                                  scanner space. Default:
                                                  register the data to the
                                                  atlas space when svort or
                                                  svort-stack are used.
                                                  (default: False)

model architecture:
  --n-features-per-level int                      Length of the feature vector
                                                  at each level. (default: 2)
  --log2-hashmap-size int                         Max log2 size of the hash
                                                  grid per level. (default:
                                                  19)
  --level-scale float                             Scaling factor between two
                                                  levels. (default: 1.3819)
  --coarsest-resolution float                     Resolution of the coarsest
                                                  grid in millimeter.
                                                  (default: 16.0)
  --finest-resolution float                       Resolution of the finest
                                                  grid in millimeter.
                                                  (default: 0.5)
  --n-levels-bias int                             Number of levels used for
                                                  bias field estimation.
                                                  (default: 0)
  --depth int                                     Number of hidden layers in
                                                  MLPs. (default: 1)
  --width int                                     Number of neuron in each
                                                  hidden layer. (default: 64)
  --n-features-z int                              Length of the intermediate
                                                  feature vector z. (default:
                                                  15)
  --n-features-slice int                          Length of the slice
                                                  embedding vector e.
                                                  (default: 16)
  --no-transformation-optimization                Disable optimization for
                                                  rigid slice transfromation,
                                                  i.e., the slice
                                                  transformations are fixed
                                                  (default: False)
  --no-slice-scale                                Disable adaptive scaling for
                                                  slices. (default: False)
  --no-pixel-variance                             Disable pixel-level
                                                  variance. (default: False)
  --no-slice-variance                             Disable slice-level
                                                  variance. (default: False)
  --no-gating                                     Disable hash grid level
                                                  gating (enabled by default).
                                                  (default: False)
  --gating-mode {standard,ff_direct}              Gating gradient mode.
                                                  'standard': MSE and FF Loss
                                                  gradients both flow to
                                                  level_weights. 'ff_direct':
                                                  encoding is detached in
                                                  patch_forward so FF Loss
                                                  gradient flows exclusively
                                                  to level_weights (G1_D
                                                  experiment). (default:
                                                  standard)
  --gating-lr-scale float                         Learning rate multiplier for
                                                  the level_weights parameter
                                                  group. Set to 10.0 for
                                                  G1_hlr experiment (faster
                                                  gating weight
                                                  differentiation). Ignored
                                                  when --no-gating is set.
                                                  (default: 1.0)
  --spatial-gating                                Enable spatially-adaptive
                                                  hash grid level gating (G6).
                                                  Instead of a single global
                                                  level_weights vector, a
                                                  small MLP (GatingMLP)
                                                  predicts per-coordinate
                                                  level weights from
                                                  normalized 3D coordinates.
                                                  This allows different
                                                  spatial regions (e.g.,
                                                  cortex vs white matter) to
                                                  emphasize different
                                                  frequency levels
                                                  independently. Requires
                                                  --no-gating to be unset. See
                                                  also --gating-hidden-dim.
                                                  (default: False)
  --gating-hidden-dim int                         Hidden layer size of the
                                                  GatingMLP used in spatially-
                                                  adaptive gating (--spatial-
                                                  gating). GatingMLP
                                                  architecture: Linear(3 -> H)
                                                  -> ReLU -> Linear(H ->
                                                  n_levels). Larger values
                                                  increase expressiveness but
                                                  add compute cost. Default:
                                                  32 (~500 parameters for
                                                  n_levels=12). Ignored when
                                                  --spatial-gating is not set.
                                                  (default: 32)
  --no-z-gating                                   Disable z_repr input to
                                                  GatingMLP (G7). By default
                                                  (when --spatial-gating is
                                                  set and this flag is NOT
                                                  set), GatingMLP receives
                                                  both 3D coordinates AND the
                                                  density_net intermediate
                                                  feature z_repr as input,
                                                  allowing content-aware
                                                  gating. Set this flag to
                                                  revert to coordinate-only
                                                  gating (G6 behaviour).
                                                  Ignored when --spatial-
                                                  gating is not set. (default:
                                                  False)
  --gating-activation {relu,silu}                 Activation function used
                                                  inside GatingMLP (--spatial-
                                                  gating). 'relu' (default):
                                                  standard ReLU — matches G12
                                                  baseline behaviour. 'silu':
                                                  Sigmoid Linear Unit (Swish),
                                                  smoother gradient flow, may
                                                  produce softer weight
                                                  distributions. Ignored when
                                                  --spatial-gating is not set.
                                                  (default: relu)
  --gating-min-weight float                       Minimum value for each level
                                                  weight output by GatingMLP
                                                  (--spatial-gating). Applied
                                                  as clamp(min=value) after
                                                  softmax*n_levels. 0.0
                                                  (default): no lower bound —
                                                  matches G12 baseline
                                                  behaviour. Recommended
                                                  values: 0.2 (G14_clamp02) or
                                                  0.5 (G14_clamp05). Prevents
                                                  any level from being
                                                  completely suppressed,
                                                  ensuring all hash grid
                                                  levels contribute to the
                                                  reconstruction. Ignored when
                                                  --spatial-gating is not set.
                                                  (default: 0.0)
  --gating-temperature float                      Temperature T for softmax in
                                                  GatingMLP: softmax(logits /
                                                  T). 1.0 (default): standard
                                                  softmax — matches G12
                                                  baseline behaviour. T > 1.0
                                                  (e.g., 1.5): flatter
                                                  distribution, weights become
                                                  more uniform. T < 1.0:
                                                  sharper distribution, more
                                                  winner-take-all behaviour.
                                                  Ignored when --spatial-
                                                  gating is not set. (default:
                                                  1.0)

  --n-features-per-level-deform int               Length of the feature vector

  --level-scale-deform float                      Scaling factor between two

                                                  (default: 1.3819)
  --coarsest-resolution-deform float              Resolution of the coarsest

                                                  (default: 32.0)
  --finest-resolution-deform float                Resolution of the finest

loss and regularization:
  --weight-transformation float                   Weight of transformation
                                                  regularization. (default:
                                                  0.1)
  --weight-bias float                             Weight of bias field
                                                  regularization. (default:
                                                  100.0)
  --image-regularization {TV,edge,L2,none}        Type of image
                                                  regularization. 1. ``TV``:
                                                  total variation (L1
                                                  regularization of image
                                                  gradient); 2. ``edge``:
                                                  edge-preserving
                                                  regularization, see `--delta
                                                  <#delta>`__\ . 3. ``L2``: L2
                                                  regularization of image
                                                  gradient; 4. ``none``: no
                                                  image regularization.
                                                  (default: edge)
  --weight-image float                            Weight of image
                                                  regularization. (default:
                                                  1.0)
  --delta float                                   Parameter to define
                                                  intensity of an edge in
                                                  edge-preserving
                                                  regularization. See
                                                  `--image-regularization
                                                  <#image-regularization>`__\
                                                  .The edge-preserving
                                                  regularization becomes L1
                                                  when ``delta`` goes to 0.
                                                  (default: 0.2)
  --img-reg-autodiff                              Use auto diff to compute the
                                                  image graident in the image
                                                  regularization. By default,
                                                  the finite difference is
                                                  used. (default: False)
  --weight-deform float                           Weight of deformation
                                                  regularization (default:
                                                  0.1)
  --weight-ff-loss float                          Weight of Focal Frequency
                                                  Loss (FF Loss). FF Loss is
                                                  computed on patch-wise FFT
                                                  maps and penalizes hard-to-
                                                  reconstruct frequency
                                                  components. Set to 0
                                                  (default) to disable FF Loss
                                                  entirely. (default: 0.0)
  --patch-size int                                Patch size (P) used for FF
                                                  Loss computation. Each patch
                                                  is a spatially contiguous
                                                  P×P region sampled from a
                                                  single slice. Ignored when
                                                  --weight-ff-loss is 0.
                                                  (default: 16)
  --n-patches int                                 Number of patches sampled
                                                  per training iteration for
                                                  FF Loss. Increasing this
                                                  value improves frequency
                                                  coverage but raises memory
                                                  usage. Ignored when
                                                  --weight-ff-loss is 0.
                                                  (default: 8)
  --ff-alpha float                                Exponent alpha for the
                                                  dynamic frequency weighting
                                                  in FF Loss. Higher values
                                                  place more emphasis on hard
                                                  (high-error) frequency
                                                  components. Recommended
                                                  range: 0.5 ~ 2.0. Ignored
                                                  when --weight-ff-loss is 0.
                                                  (default: 1.0)
  --weight-diversity-loss float                   Weight of Diversity Loss for
                                                  level_weights
                                                  differentiation. Penalizes
                                                  low variance of
                                                  level_weights, encouraging
                                                  the gating to differentiate
                                                  hash grid levels.
                                                  Recommended starting value:
                                                  0.01. Ignored when --no-
                                                  gating is set or when set to
                                                  0 (default). (default: 0.0)
  --target-diversity-var float                    Target variance for
                                                  Diversity Loss (soft target
                                                  mode). When variance of
                                                  level_weights exceeds this
                                                  value, the diversity loss
                                                  becomes 0 (no further push),
                                                  preventing divergence. Only
                                                  used when --weight-
                                                  diversity-loss > 0 and --no-
                                                  gating is not set. Default:
                                                  0.05 (stable level observed
                                                  in G2_div001). For softmax-
                                                  output-based diversity
                                                  (--diversity-loss-
                                                  space=softmax), a larger
                                                  value such as 0.5 is
                                                  recommended. (default: 0.05)
  --diversity-loss-space {raw,softmax}            Space in which the Diversity
                                                  Loss variance is computed.
                                                  'raw' : variance of raw
                                                  level_weights (logit space).
                                                  G3_softvar experiment.
                                                  'softmax': variance of softm
                                                  ax(level_weights)*n_levels
                                                  (actual gating output). More
                                                  stable target space.
                                                  G3_softvar_softmax
                                                  experiment. Ignored when
                                                  --weight-diversity-loss is 0
                                                  or --no-gating is set.
                                                  (default: raw)
  --diversity-loss-fn {variance,entropy,gini}     Diversity metric used for
                                                  computing the Diversity
                                                  Loss. 'variance' (default):
                                                  penalizes low variance of
                                                  level_weights. Loss =
                                                  relu(target_var -
                                                  var(weights)). G5_lowvar
                                                  baseline. 'entropy' :
                                                  penalizes high entropy
                                                  (uniform distribution). Loss
                                                  = relu(entropy(softmax(weigh
                                                  ts)) - target_var). Lower
                                                  entropy => more
                                                  differentiated levels.
                                                  'gini' : penalizes high Gini
                                                  impurity (uniform
                                                  distribution). Loss =
                                                  relu(gini(softmax(weights))
                                                  - target_var). Lower Gini =>
                                                  more
                                                  concentrated/differentiated
                                                  weights. Ignored when
                                                  --weight-diversity-loss is 0
                                                  or --no-gating is set.
                                                  (default: variance)
  --gating-grad-clip float                        Max norm for gradient
                                                  clipping applied to the
                                                  level_weights parameter
                                                  group. Set to 1.0 to enable
                                                  clipping (recommended when
                                                  --weight-diversity-loss >
                                                  0). Set to 0 (default) to
                                                  disable clipping. Ignored
                                                  when --no-gating is set.
                                                  (default: 0.0)
  --gating-warmup-iters int                       Number of iterations to
                                                  freeze density_net at the
                                                  start of training, allowing
                                                  level_weights to
                                                  differentiate before
                                                  density_net adapts. Set to 0
                                                  (default) to disable warmup
                                                  freeze. Recommended starting
                                                  value: 500 (~10% of default
                                                  n_iter=6000). Ignored when
                                                  --no-gating is set.
                                                  (default: 0)

training:
  --learning-rate float                           Learning rate of Adam
                                                  optimizer. (default: 0.005)
  --gamma float                                   Multiplicative factor of
                                                  learning rate decay.
                                                  (default: 0.33)
  --milestones float [float ...]                  List of milestones of
                                                  learning rate decay. Must be
                                                  in (0, 1) and increasing.
                                                  (default: [0.5, 0.75, 0.9])
  --n-iter int                                    Number of iterations for
                                                  training. (default: 6000)
  --n-epochs int                                  Number of epochs for
                                                  training. If provided, will
